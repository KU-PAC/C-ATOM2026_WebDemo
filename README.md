# PatchAssist 3D Demo

公開デモ: <https://challenge-atom-kyoto.raptor-s.workers.dev/>

湿布貼付支援ロボット「PatchAssist」の、クライアント提示用インタラクティブデモです。
OpenArm 2.0 の双腕で、次の 4 工程をひと続きに実行するところまでを可視化します。

| 工程 | 内容 | 主要素 |
| --- | --- | --- |
| 01 Depth scan | 胸部の RealSense で背中を撮り、cm 精度の 3D モデルを起こす | 点群の逐次取得 → 等高線化 |
| 02 Intent capture | 貼ってほしい場所を本人に手で押さえてもらい、指先を貼付点として確定する | MediaPipe 21 点ランドマーク → 背中メッシュへ投影 |
| 03 Vacuum peel | 12V 真空ポンプ 2 台で湿布の両端を吸引。片方は固定、もう片方が揺すって剥離ライナーを剥がす | 吸着圧・剥離進捗のテレメトリ |
| 04 Force control | 接触した瞬間を力で捉え、目標押付力を保ったまま端から圧着する | Fz 監視 → 4 N 制御 |

3D デモの下には、システム構成図・工程別諸元・BOM とコスト・力覚センサの三案比較・
リスクと検証計画・出典をまとめた技術ドシエを載せています。数値は公開資料から引用し、
未実測のものは「推定」と明記しています。

## 起動

```bash
npm install
npm run dev
```

本番ビルドは `npm run build`、ビルド結果の確認は `npm run preview` です。
公開は `npm run deploy`。ビルドして `dist/` を Cloudflare Workers へ直接アップロードします
（宛先は `wrangler.jsonc` の `name`。ここを変えると公開 URL が変わります）。

## 操作

- 「動作シーケンスを再生」または再生ボタンでシーケンスを再生
- タイムラインをドラッグして任意の時点へ移動（一時停止中はカメラとアームが即座に追従）
- 工程リスト、または数字キー `1`〜`4` で工程へジャンプ
- `Space` で再生・一時停止、`R` でリセット
- 3D エリアをドラッグして視点を回転（工程が変わると自動フレーミングに戻ります）
- 右上のボタンで「工程に追従」／「全体」ビューを切り替え

開発時のみ、`?p=0.6`（再生位置）、`?view=wide`、`?scroll=2400` のクエリでスクリーンショット
用に任意の状態へ固定できます。

## 実装のかんどころ

**双腕はタスク空間で駆動しています。** 関節角を手で並べるのではなく、
`src/lib/trajectory.json` に「吸着カップをどこに、どちら向きに置くか」だけを書き、
`src/lib/ik.ts` の減衰最小二乗 IK（7 自由度・特異点近傍で減衰、冗長軸は基準姿勢へ引き戻し）
が毎フレーム解いています。URDF の可動域・軸・原点をそのまま使うため、
デモで見える姿勢はすべて OpenArm 2.0 の可動範囲内です。

42 秒のシーケンス全区間について、目標手先位置への追従誤差が **5 mm 以内** に収まることを
オフラインで確認済みです（両腕・1200 サンプル）。

**湿布・剥離ライナー・貼付済みの湿布も同じ座標から作っています。** ライナーは毎フレーム
吸着カップの実位置を終点とする曲線に沿ってリボンを張り直すため、剥離の途中でカップと
フィルムがずれることがありません。貼付済みの湿布は背中の曲面上に生成し、圧着の進行に
合わせて下端から順に出現します。

**人体は生成しています。** 再配布可能な既製アバターはいずれも背中が衣服と髪で覆われて
おり、このデモが見せたい面そのものが隠れてしまいます。`src/lib/anatomy.ts` の
パラメトリック曲面から胴体・点群・等高線・貼付面をすべて導出しているため、
4 つの表現が構成上ずれません。

## 3D モデル

ロボットアームとエンドエフェクタのマウントは、Enactic, Inc. が公開している
[OpenArm Description](https://github.com/enactic/openarm_description) の OpenArm 2.0 モデルです。
Apache License 2.0 に基づいて同梱しています。詳細は [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)
と `public/models/openarm/licenses/Apache-2.0.txt` を参照してください。

同梱の Collada には Blender の既定ライトとカメラが書き出されたまま残っており、そのまま
読み込むとシーン全体が白飛びします。読み込み後に除去しています（`src/components/scene/OpenArmRig.tsx`）。
